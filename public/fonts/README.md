# Local UI fonts

The owner approved OFL-licensed alternatives to Cabinet Grotesk and Satoshi on
2026-10-29. Fontshare's downloaded ITF FFL 2.0 permits self-hosting but restricts
repository redistribution, so no Fontshare font binaries are included here.

- **Archivo**, Latin variable WOFF2, weights 400–800: display headings.
- **Manrope**, Latin variable WOFF2, weights 400–800: UI/body copy.
- **Noto Sans Arabic**, Arabic variable WOFF2, weights 400–800: Arabic glyphs.

These are unmodified webfont subsets supplied by Google Fonts. The matching
upstream OFL notices are kept beside the fonts. All runtime requests are local;
there is no Google Fonts or Fontshare stylesheet, preconnect, or runtime import.
Scripts outside these subsets use the system fallback stack; source filenames
and file contents are never changed by typography.
